# TikTok Web Archive

Статическая стартовая страница архива публичных страниц TikTok.

## Возможности

- Поиск по сохранённым карточкам профилей и видео;
- Адаптивная вёрстка для мобильных устройств;
- Визуальная страница архива без зависимости от backend;
- Фильтр карточек по типу архива.

## Запуск

Откройте `index.html` в браузере или опубликуйте репози��орий через GitHub Pages.

> Данные на странице демонстрационные. Для настоящего архива потребуется backend, база данных и соблюдение правил TikTok, авторских прав и robots.txt.
